Old jewel - old jewel received from customer - value in grams
Expenses - apart from cash depositing into bank, all other payments values should be calculated here
Purchase - GRN (GST) raised weight in grams and values should be shown here
Cash Vs Stock - collection (amount collected - payment entries excluding Cash depositing into bank) / (today metal price + average labour cost) 
Average labour cost is Rs. 100/- (static value)
Increase in stock = Total stock(purchase) - capital stock
Average value = (capital value (grams)  + purchase value (grams)) / ( capital value weight + purchase value weight)
Profit value = (Increase in stock * average value) and old silver weight.
